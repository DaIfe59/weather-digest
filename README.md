# Weather Digest

Консольное приложение на Node.js для получения прогноза погоды по одному или нескольким городам с использованием Open-Meteo REST API.

Приложение выполняет поиск города по названию, получает его координаты, запрашивает прогноз погоды на заданное количество дней, выводит результат в консоль и сохраняет отчёт в формате JSON.

## Возможности

- поиск города по названию через Open-Meteo Geocoding API;
- получение прогноза погоды на срок от 1 до 7 дней;
- обработка нескольких городов за один запуск;
- параллельная обработка городов;
- независимая обработка ошибок для каждого города;
- вывод информации о городе, стране и координатах;
- вывод минимальной и максимальной температуры;
- вывод количества осадков;
- сохранение результатов в JSON-файлы;
- кэширование результатов на текущую дату;
- возможность принудительно обновить данные через `--no-cache`;
- настройка параметров приложения через переменные окружения;
- ограничение времени ожидания HTTP-запросов;
- обработка сетевых ошибок и ошибок API.

Указывает один или несколько городов.

Один город:

npm start -- --city "Москва"

Несколько городов:

npm start -- --city "Москва, Берлин, Париж"

Города обрабатываются параллельно.

--days

Необязательный параметр.

Определяет количество дней прогноза.

Допустимые значения:

1–7

По умолчанию используется:

3

Пример:

npm start -- --city "Москва" --days 5
--no-cache

Игнорирует существующий кэш и принудительно получает свежие данные из API.

Пример:

npm start -- --city "Москва" --days 3 --no-cache

Кэширование

После получения прогноза приложение сохраняет отчёт в каталог reports.

При следующем запуске приложение проверяет наличие отчёта за текущую дату.

Если подходящий отчёт найден, данные берутся из локального файла без повторного обращения к API.

Для принудительного обновления используется:

npm start -- --city "Москва" --days 3 --no-cache
Отчёты

Отчёты сохраняются в формате JSON.

По умолчанию используется каталог:

reports/

Имя файла формируется по шаблону:

{город}-{ГГГГ-ММ-ДД}.json

Например:

reports/Москва-2026-09-12.json

Пример содержимого отчёта:

{
  "date": "2026-09-12",
  "city": "Москва",
  "country": "Россия",
  "coordinates": {
    "latitude": 55.75204,
    "longitude": 37.61781
  },
  "forecast": [
    {
      "date": "2026-09-12",
      "minTemperature": 9.6,
      "maxTemperature": 17.1,
      "precipitation": 0
    }
  ]
}

Каталог reports/ не добавляется в Git.

Обработка ошибок

Приложение обрабатывает:

отсутствие параметра --city;
некорректный параметр --days;
значение --days вне диапазона 1–7;
неизвестные аргументы;
ненайденный город;
ошибки API 4xx;
ошибки API 5xx;
отсутствие подключения к сети;
превышение времени ожидания;
некорректный JSON;
неожиданный формат ответа API;
ошибки чтения и сохранения отчётов.

Ошибка одного города не останавливает обработку остальных городов.

Коды завершения
Код	Значение
0	Все города обработаны успешно
1	При обработке произошла ошибка

В PowerShell код завершения можно проверить командой:

$LASTEXITCODE

Описание модулей
src/index.js

Точка входа приложения.

Отвечает за запуск программы, обработку аргументов, параллельное получение данных, вывод результатов и установку кода завершения.

src/cli/args.js

Обрабатывает аргументы командной строки:

--city;
--days;
--no-cache.

Также проверяет корректность переданных параметров.

src/api/openMeteo.js

Отвечает за взаимодействие с Open-Meteo API.

Использует Geocoding API для поиска города и Forecast API для получения прогноза.

Также обрабатывает HTTP-ошибки, сетевые ошибки, таймауты и некорректный JSON.

src/services/weatherService.js

Содержит основную бизнес-логику приложения.

Отвечает за проверку кэша, получение координат, получение прогноза, формирование и сохранение отчёта.

src/storage/reports.js

Отвечает за работу с JSON-файлами отчётов и локальным кэшем.

src/format/console.js

Отвечает за форматирование и вывод результатов в консоль.

src/config/config.js

Содержит конфигурацию приложения и значения переменных окружения.

API

Проект использует два Open-Meteo API.

Geocoding API

Используется для поиска города и получения его координат.

GET https://geocoding-api.open-meteo.com/v1/search

Основные параметры:

name
count
language
format
Forecast API

Используется для получения прогноза по координатам.

GET https://api.open-meteo.com/v1/forecast

Основные параметры:

latitude
longitude
daily
forecast_days
timezone
temperature_unit
Postman

Для проверки API подготовлена коллекция:

docs/postman/weather-digest.postman_collection.json

Коллекция содержит два запроса:

Geocoding;
Forecast.
Geocoding Examples
200 - City found
200 - City not found
Forecast Examples
200 - Forecast success
400 - Invalid parameters

Коллекция экспортирована в формате Postman Collection v2.1.
